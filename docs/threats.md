# Модели угроз в IS Manager

Откройте **Обзор → Модели угроз** (`/threats/`). На первом шаге можно заполнить профиль системы или импортировать Excel. На ноутбуке слева видны 11 шагов. На телефоне откройте **Шаги анкеты**. Завершённый шаг доступен из списка, следующий открывается после проверки обязательных полей. **Сохранить черновик** позволяет отложить заполнение. Кнопка **Все мои анкеты** возвращает к списку с сохранением полей редактируемого шага.

В **Моих анкетах** видны текущий шаг или отметка **Документы сформированы**. Поиск работает по названию, страницы содержат до 50 анкет. Из **Обзор → Последние материалы** черновик открывается на достигнутом шаге. Анкета, схема сети и готовый архив принадлежат текущему рабочему пространству браузера или учётной записи.

1. Выберите назначение системы и сетевые условия. Если применимы дополнительные признаки, раскройте **Значимость системы**. Поддерживаются отдельная ИСПДн и объект для размещения нескольких систем.
2. Укажите оператора, систему, категории персональных данных и субъектов. Для субъектов, не являющихся сотрудниками, задайте объём обработки.
3. Опишите инфраструктуру и средства защиты. Схему PNG или JPEG до 2 МБ можно приложить к модели. Сервер перечитывает и перекодирует изображение.
4. Проверьте последствия, нарушителей, их цели и решения по банку угроз. Поиск принимает код или фрагмент названия. Вручную изменённые решения сохраняются отдельно от рекомендаций. Для систем ИИ учитываются инфраструктура оператора и, при дообучении модели или работе со своими данными RAG, инфраструктура разработчика.
5. Заполните сведения о типе угроз, СКЗИ и комиссии. По правилу исходной анкеты состав комиссии включает председателя и не менее двух членов. В описании каждой меры можно выбрать типовую формулировку или ввести свой вариант.
6. Выберите комплект и нажмите **Сформировать и скачать ZIP**. Когда документы готовы, браузер начинает скачивание архива с редактируемыми DOCX. Для повторной загрузки используйте **Скачать документы (.zip)** или кнопку **ZIP** в списке анкет. Изменение анкеты сбрасывает сформированный архив. Комиссия сверяет сведения, дополняет фактические результаты проверок и утверждает документы.

## Excel и состав комплекта

На первом шаге **Профиль системы** нажмите **Скачать пример шаблона (Excel)**. Заполните столбец B и выберите **Загрузить заполненный файл**. Подсказку можно раскрыть через **Как заполнить шаблон**. Поля и подписи основного листа совместимы с вертикальной анкетой исходного генератора. Для обмена с заказчиком откройте **Действия с анкетой → Скачать поля анкеты (.xlsx)**. Решения по отдельным угрозам, список отмеченных последствий, схема сети и текстовые способы реализации мер хранятся в IS Manager. Полная резервная копия включает базу приложения.

Базовый комплект включает модель угроз, акт определения УЗ и акт выбора мер. Расширенный комплект добавляет протокол оценки вреда, технический паспорт, матрицу ролей, перечни пользователей и третьих лиц, акты ввода и оценки эффективности, приказ о комиссии. Отдельно доступны заключение по безопасной разработке, политика и приказ по ПДн, парольная политика и регламенты по инцидентам, антивирусной защите, доступу, резервному копированию и обновлениям. Всего можно получить 20 файлов. Параметры в проектах локальных актов, сроки и заполненные поля проверяет оператор при утверждении. Акт эффективности содержит место для фактических свидетельств и результатов проверки.

## Расчёты и источники

Встроенный справочник воспроизводит состояние внутреннего исходного генератора на 18 ноября 2026 года. В нём 243 угрозы из интервала УБИ.001–248, пять номеров УБИ.218–222 архивные. Для актуальных угроз раздел сценариев показывает применимые тактики и идентификаторы техник приложения 11 к методике 2021 года. Эксперт вписывает оценку конкретных сценариев на шаге 7. [БДУ ФСТЭК России](https://bdu.fstec.ru/threat) · [Подраздел об ИИ](https://bdu.fstec.ru/threat/ai).

Уровень защищённости определяется по 48 сочетаниям типа угроз, категории ПДн, субъекта и объёма из таблицы исходного калькулятора по ПП РФ № 1119. При нескольких категориях выбирается наиболее строгий результат. Для объекта размещения используется заявленный предел. Встроены 109 мер по приказу ФСТЭК № 21 и два независимых основания для расчёта класса СКЗИ по приказу ФСБ № 378. Выбирается более строгий из класса по таблице и класса по модели нарушителя. [Текст ПП РФ № 1119 на сайте Минобрнауки России](https://minobrnauki.gov.ru/open_ministry/gossluzhba/entry/files/%D0%9F%D0%BE%D1%81%D1%82%D0%B0%D0%BD%D0%BE%D0%B2%D0%BB%D0%B5%D0%BD%D0%B8%D0%B5%20%D0%9F%D1%80%D0%B0%D0%B2%D0%B8%D1%82%D0%B5%D0%BB%D1%8C%D1%81%D1%82%D0%B2%D0%B0%20%D0%A0%D0%A4%20%D0%BE%D1%82%2001.11.2012%20N%201119%20%20%D0%9E%D0%B1%20%D1%83%D1%82%D0%B2%D0%B5.pdf).

Шаблоны DOCX написаны для публичного Python-продукта с учётом структуры исходного генератора. Образцы из архивов организаций, реквизиты клиентов и лицензии PHP-библиотек в поставку не входят. Для новых требований и отраслевых методик необходимо проверить применимость нормативных ссылок и обновить справочник.

## Разработчику

Маршруты и хранение анкет реализованы в `app/threats.py`. Функции `profile`, `conclusions` и `assess` в `app/threat_model/__init__.py` принимают обычный словарь. Каталог `catalog.json` версионируется с релизом. Запросы ограничены владельцем. Изменение требует актуальной ревизии анкеты. Хранение архива и схемы внутри SQLite обеспечивает согласованность с резервной копией пользовательских данных.

Экспорт использует python-docx (MIT) и openpyxl (MIT). Проверка XML использует defusedxml (PSF), изображения обрабатывает Pillow (MIT-CMU). Веса нейросетей для этого модуля не требуются. [python-docx](https://github.com/python-openxml/python-docx/blob/master/LICENSE) · [openpyxl](https://openpyxl.readthedocs.io/en/stable/#license) · [defusedxml](https://github.com/tiran/defusedxml/blob/main/LICENSE) · [Pillow](https://pillow.readthedocs.io/en/stable/about.html#license).

Из корня после установки зависимостей выполните `python -m unittest discover -s tests -p test_threats.py -v`. Проверки охватывают расчёты, эталонные решения исходного генератора по всем 243 угрозам для двух профилей, повреждённый XLSX, импорт и экспорт, последовательность шагов, доступ владельца, параллельное редактирование и открытие полного комплекта из 20 DOCX.
