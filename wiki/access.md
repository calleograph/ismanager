# Как предоставить администратору доменный вход

Сотруднику для расшифровки записи или создания анкеты достаточно открыть главный адрес IS Manager. Подключение LDAP или Active Directory нужно, когда настройки экземпляра должны обслуживать доменные администраторы.

1. Войдите локальным администратором и откройте **Система → Каталоги → Добавить подключение**.
2. Укажите тип каталога, сервер, протокол, порт, Base DN и сервисную запись с доступом на чтение. Для внутреннего центра сертификации добавьте сертификат CA в **Параметрах домена и TLS**. Сохраните подключение.
3. В поле **Найти пользователя или группу** введите часть имени, логина или названия группы. Выберите запись из результатов. Проверьте, что профиль и вход администраторов каталога включены, затем нажмите **Сохранить подключение**.
4. Оставьте текущую административную вкладку открытой. В отдельном окне приватного просмотра войдите под выбранной доменной записью. После обязательной смены пароля или подключения второго фактора, если этого требует политика, должна открыться запрошенная административная страница.

Если тестовый вход не удался, откройте **Диагностика подключения** в карточке каталога. Последовательно проверьте доступность сервера, TLS, служебный вход и чтение каталога. При ошибке сохранения нового профиля интерфейс сохраняет введённые несекретные параметры. Пароль сервисной записи потребуется ввести повторно.

В **Система → Пользователи** появляются учётные записи, которые уже входили. Из строки пользователя можно перейти к его событиям в журнале. При входе по локальной ссылке IS Manager возвращает администратора к запрошенному экрану.
