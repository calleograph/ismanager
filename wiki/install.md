# Установка на выделенном или общем сервере

Сначала выберите адрес, который сотрудник откроет с рабочего компьютера. Если на сервере уже работает Nginx, его внешний адрес может отличаться от порта контейнера. IS Manager хранит данные в SQLite в собственном томе Docker. Создавать базу на сервере предприятия для этой установки не требуется.

На выделенной Ubuntu 24.04 установщик может поставить необходимые пакеты, включая Docker и Compose v2. Режим общего сервера использует уже установленный Docker. Для работы на CPU ориентируйтесь на 4 ядра, 8 ГиБ памяти и 20 ГиБ диска плюс место для материалов и резервных копий. Для начальной сборки и загрузки моделей нужен доступ к источникам из интернета.

## Выберите одну команду установки

Скачайте установщик и выберите команду для своего размещения. В примерах для общего сервера замените имя и порты своими значениями.

```sh
wget -O "$HOME/install-ismanager.sh" https://raw.githubusercontent.com/calleograph/ismanager/v0.6.0/install.sh
```

**Выделенный сервер, прямой HTTP в доверенной сети**

```sh
sudo bash "$HOME/install-ismanager.sh" --ref v0.6.0 --access http
```

**Общий сервер, свободный порт 18085**

```sh
sudo bash "$HOME/install-ismanager.sh" --ref v0.6.0 \
  --shared-host --access http --port 18085
```

**Nginx принимает HTTP на порту 8106, контейнер слушает порт 18086 на loopback**

```sh
sudo bash "$HOME/install-ismanager.sh" --ref v0.6.0 \
  --shared-host --access proxy --bind 127.0.0.1 --port 18086 \
  --public-url http://ismanager.example.org:8106
```

**Nginx на том же сервере принимает HTTPS, для контейнера выделен порт 18086**

```sh
sudo bash "$HOME/install-ismanager.sh" --ref v0.6.0 \
  --shared-host --access proxy --bind 127.0.0.1 --port 18086 \
  --public-url https://ismanager.example.org
```

В режимах с прокси направьте запросы от выбранного имени Nginx на `http://127.0.0.1:18086`. Подставьте этот порт и свой домен в пример конфигурации. Для HTTPS укажите также действующий сертификат и ключ. Проверьте конфигурацию командой `sudo nginx -t` и примените её. Для отдельного прокси-сервера меняются привязка и адрес доверенного прокси, этот вариант разобран в руководстве. [Пример для HTTP](https://github.com/calleograph/ismanager/blob/v0.6.0/docs/nginx-http.conf.example) · [Пример для HTTPS](https://github.com/calleograph/ismanager/blob/v0.6.0/docs/nginx.conf.example) · [Варианты размещения](https://github.com/calleograph/ismanager/blob/v0.6.0/docs/ADMIN.md#сетевой-доступ)

## Что проверить с рабочего места

Установщик выводит этапы сборки, загрузки модели и проверки готовности, затем адрес и начальный пароль администратора. Откройте напечатанный внешний адрес с другого компьютера. В примере с HTTP-прокси это `http://ismanager.example.org:8106/`. По пути `/healthz` на том же адресе приложение возвращает статус `ok` и номер версии. По HTTP файлы и пароль идут по сети открытым текстом. Для доступа за пределами доверенной сети используйте HTTPS или защищённое соединение VPN.

На главной должны открыться четыре рабочих раздела. Для настройки системы нажмите **Вход администратора**, войдите под именем `admin` и смените начальный пароль. [Доменный вход](access.md) · [Обновление установленного экземпляра](updates.md) · [В начало Wiki](Home.md)
